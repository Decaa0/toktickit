# Lab 2 Zen Green UI Specification[cite: 2]

## Visual Design Tokens[cite: 2]
- **Primary Green**: `#006B3C` (Header bar, Primary Submit buttons)[cite: 2]
- **Secondary Green**: `#0B7A46` (Active nav tabs, hover states)[cite: 2]
- **Pale Green**: `#EAF6EF` (Success notices, active requester highlights)[cite: 2]
- **Background**: `#F5F7F6` (Neutral off-white page canvas)[cite: 2]
- **Card Surfaces**: `#FFFFFF` with `#E2E8F0` border and soft shadow[cite: 2]
- **Error Callouts**: `#FFF5F5` background, `#C53030` text, `#FEB2B2` border[cite: 2]

## Responsive Breakpoints[cite: 2]
- **Desktop (>= 992px)**: Multi-column grid for form classification and ticket data; full table view in My Tickets[cite: 2].
- **Tablet (768px - 991px)**: Two-column layout with expanded summary and description blocks[cite: 2].
- **Mobile (< 768px)**: Single-column vertical stack, touch-friendly buttons, horizontal scroll protection[cite: 2].
