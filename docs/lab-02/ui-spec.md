# Lab 2 UI Specification

## Layout & Components
* **Requester Selector**: Dropdown component in navigation bar to toggle active context.
* **Create Ticket View**: Responsive form with field validation and multi-file attachment dropzone.
* **My Tickets View**: Paginated data table with real-time status and category filtering.
* **Ticket Detail View**: Ticket header summary, file attachment list, and soft-remove confirmation modal.
