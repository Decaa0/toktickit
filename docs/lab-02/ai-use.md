# Lab 2: AI Use and Reflection

## 1. How I Used AI
- **What I allowed the AI to do:**
  - Create the starting layout for my documents and test plans
  - Write basic setup code for my API and database.
  - Format tables and Git commands to match the lab rules.
- **What I did NOT let the AI do:**
  - Copy code blindly without checking it first.
  - Let the AI change the core rules of the project.
  - Trust the AI when it said the tests passed (I ran all tests myself on my computer)
